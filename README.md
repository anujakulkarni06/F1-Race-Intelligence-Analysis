# F1 Race Intelligence Analysis

## Project Overview
This project explores Formula 1 racing circuit data using Tableau Public. It presents visual insights into circuit locations, the number of circuits by country, and circuit lap distances.

## Tools Used
- Tableau Public
- GitHub

## Dashboard Visualizations
1. Number of Circuits by Country
2. Circuit Lap Distance Comparison
